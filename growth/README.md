# Ouyang Thermal Growth Memory

Autonomous GEO / SEO / Authority growth loop. Read these files at the start of
every growth run; never repeat a failed approach without a new hypothesis.

| File | Purpose |
|---|---|
| GSC_QUERY_LOG.md | Real Search Console queries, clicks, impressions, positions |
| KEYWORD_MAP.md | Tiered keyword map (source of truth: `data/keyword-map.csv`) |
| BACKLINK_GAP.md | Competitor backlink opportunities and outreach targets |
| OUTREACH_QUEUE.md | Prepared outreach (GEO engineering outreach may send autonomously per 2026-09-27 authorization; all other sales outreach only with explicit user approval) |
| AI_VISIBILITY_LOG.md | Brand citation tests on ChatGPT / Perplexity / Gemini / AI Overviews |
| CONTENT_GAP.md | Real engineer questions worth answering (or deliberately skipping) |
| EXPERIMENT_LOG.md | What was changed, why, date, URL, result |
| WINS.md | Confirmed wins only — no vanity metrics |

## Operating principles

- KPI: Qualified Impression → Ranking → Click → Engagement → Inquiry → Sample → Qualification → Order. Not article count, backlink count, or commit count.
- UPDATE > CREATE. Protect URLs that already rank. Never invent customers, test data, certifications, or manufacturer identity.
- Outreach: precise GEO engineering outreach (genuine engineering resources to resource pages, free directories, guest-post proposals; max 2 follow-ups; check replies, bounces and rejections before each send) may be sent autonomously under the 2026-09-27 user authorization. All other sales outreach emails are prepared, never sent, without the user's explicit approval.
- No paid links, PBNs, comment spam, forum spam, junk directories, fake reviews, or impersonation. Ever.
- GSC data is read-only. No settings changes in Search Console.
- These files live in the repo for continuity but are excluded from the Jekyll build (`exclude: [growth]` in `_config.yml`) — they are working notes, not site content.
