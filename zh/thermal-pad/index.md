<div class="quick"><strong>直接回答</strong><p>选择导热垫片时，先用最小/最大间隙确定厚度和压缩窗口，再确认总压缩力、实际热阻、电气绝缘、模切装配和老化后的接触稳定性。供应商提供一个高W/m·K样品，只能进入筛选，不能代表第二供应商已经通过量产验证。</p></div>

## 高W/m·K为什么不等于低热阻

垫片的实际热路径包括材料本体和两侧接触界面。名义导热系数较高，但如果材料更厚、太硬、局部未接触或压力不均，整机温度仍可能更差。对比候选材料时至少统一：压缩后厚度、接触面积、压力、表面、温度和测试方法。

## 厚度、压缩率和硬度要一起看

不能只用“标称间隙×固定百分比”选择厚度。先建立公差栈：器件高度、PCB变形、壳体平面度、装配限位和垫片厚度公差。最大间隙必须保持接触，最小间隙下的压缩力又不能损伤器件或板卡。

硬度数据必须附带测试方法和条件。相同硬度数字不代表相同压缩力；大面积垫片即使单位面积压力不高，总力也可能很大。应查看压缩—载荷曲线，并在实际接触面积上评估。

## 供应商资格验证的12项核心逻辑

| 项目 | 要回答的问题 |
| --- | --- |
| 1. 需求定义 | 间隙、面积、温度、受力和绝缘功能是否冻结？ |
| 2. 数据方法 | 导热、硬度、电气数据的方法和样品条件是否明确？ |
| 3. 模切尺寸 | 外形、孔位、缺口和定位是否符合图纸？ |
| 4. 厚度 | 多点厚度及公差是否稳定？ |
| 5. 压缩 | 最小/最大间隙下能否同时满足接触与受力？ |
| 6. 热学 | 是否在相同BLT、压力和温度下比较热阻？ |
| 7. 电气 | 测试厚度、电极、环境和老化条件是否对应实际绝缘功能？ |
| 8. 可靠性 | 循环、湿度、振动后是否仍保持接触与完整性？ |
| 9. 离型膜与装配 | 是否容易剥离、定位，是否产生碎屑或撕裂？ |
| 10. 多批次 | 原材料与成品模切的批次差异是否受控？ |
| 11. Pilot Build | 量产工装、操作员、检测和返修是否验证？ |
| 12. 变更与RFQ | 配方、原料、产地、刀模、离型膜和方法变更是否通知？ |

## Second Source从送样到RFQ

建议状态顺序：`Sample → 同条件Benchmark → 可靠性 → 多批次 → Pilot Build → Supplier Qualification → RFQ`。任何阶段失败，都应回到需求、材料或工艺原因分析，而不是降低验收标准。

RFQ前应冻结材料和成品料号、图纸版本、包装、检验项目、质量文件、数量范围和变更规则。否则不同供应商的报价并不基于同一个要求。
