## 覆盖的材料和应用

核心材料包括导热垫片、导热凝胶、导热脂、导热绝缘片、灌封材料和结构导热胶。典型应用包括光模块、AI服务器、IGBT与SiC功率模块、OBC、DC-DC、PCS、储能和电池包。

应用名称不能直接决定材料。例如，同为OBC，功率模块与冷板可能需要薄界面，磁性器件与壳体可能存在较大公差，PCB器件又可能受到装配压力限制。应把每个热路径拆开定义，再决定材料类型。

## 从技术答案到量产验证

建议路径是：`需求定义 → 同条件Benchmark → Sample → 可靠性验证 → 多批次检查 → Pilot Build → 供应商资格 → RFQ`。

欧阳热力提供工程知识、应用分析、TIM选型和对标思路。商业询盘、样品、RFQ及供应链协调由现有披露的商业实体处理；不以网站内容暗示制造所有权、客户授权或未经验证的认证。
