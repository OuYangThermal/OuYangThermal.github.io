<div class="quick"><strong>直接回答</strong><p>导热凝胶适合高度差复杂、间隙变化较大或装配压力受限的界面，但必须把材料性能与点胶工艺一起验证。选型时不能只看导热系数和黏度；还要验证设备兼容性、出胶量、轨迹、混合与固化、装配后的BLT，以及温度循环后的空洞、塌陷和Pump-Out。</p></div>

## Pad还是Gel

| 判断条件 | 导热垫片更常见 | 导热凝胶更常见 |
| --- | --- | --- |
| 间隙与表面 | 间隙相对明确，适合预成型放置 | 多器件高度不同、表面复杂或间隙变化大 |
| 装配压力 | 可以接受一定压缩力 | 希望降低器件和PCB受力 |
| 工艺 | 模切、离型膜、定位和贴装 | 计量、混合、点胶、装配与固化 |
| 主要风险 | 厚度、压缩不足或过压 | 空洞、塌陷、泵出、挤出、固化不良 |
| 返修 | 可取出，但可能粘附或撕裂 | 需要清理并恢复点胶工艺 |

最终选择取决于结构和制程，不应根据应用名称直接指定。

## 单组份与双组份怎么判断

单组份材料减少了现场配比步骤，但仍需控制储存、回温、料筒状态、停机时间和出胶稳定性。双组份导热凝胶需要进一步控制A/B比例、混合均匀性、混合管、可操作时间、固化温度和固化时间。

双组份材料表面变干或不粘，并不能单独证明内部完全固化。应采用供应商确认的方法和项目批准的过程指标，不要自行编造通用回温、搅拌或固化条件。

## 五类常见失效怎么排查

| 现象 | 优先检查 | 验证方式 |
| --- | --- | --- |
| Void 空洞 | 物料调节、混合、点胶中断、轨迹和合盖顺序 | 截面、成像或项目认可的覆盖率方法 |
| Slump 塌陷 | 温度、等待时间、胶条尺寸和垂直方向 | 装配/固化前后的位置与形状 |
| Pump-Out 泵出 | 间隙、循环位移、表面状态和黏附 | 循环后的边界、质量、覆盖和热响应 |
| Squeeze-Out 挤出 | 出胶量、合盖速度、限位和禁胶区 | 污染、溢胶与覆盖检查 |
| Incomplete Cure 固化不良 | 配比、混合、时间、温度和材料相容性 | 批准的固化指标及机械检查 |

不存在适用于所有产品的统一空洞率或Pump-Out标准。验收限值应由实际热路径、绝缘要求和失效风险决定。

## 点胶与供应商验证

记录包装形式、泵、管路、阀、混合管、针嘴、单次出胶量、胶条轨迹、节拍、排胶和停机重启。实验室手工点胶通过，不代表量产设备可以稳定运行。

多批次验证应使用同一设备和程序，比较出胶质量、胶条轮廓、混合比例、固化、装配后BLT、热学结果与可靠性表现。Pilot Build还应覆盖正常操作员、换料、排胶、停机重启、检验和返修。

供应商变更控制至少应覆盖配方、填料、原料来源、包装、生产地点、混合方案、测试方法和保质期。样品通过只是进入下一阶段，不等于量产批准。
